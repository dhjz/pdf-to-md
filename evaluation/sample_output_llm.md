# 复杂文档解析对齐样例:混合版式

本样例用于验证 Rust 解析管线与 MinerU Python 输出在复杂版式下的一致性:双栏正文、项目符号、代码块、内嵌截图、合并单元格、无线费率表以及跨页长表格都包含在内。

## 1. 双栏正文与行内格式

左栏:Rust 版本直接从 PDF 文本层读取行与坐标，再按版面区域合并。对于文本稀疏的区域会回退到 Layout/OCR管线。数值 2026、术语MinerU、标点（逗号、分号；冒号:）都保留原文。

右栏:Python 版本由 MinerU 4.2.3 导出 Markdown。两栏内容在同一视觉行，但阅读顺序应先左后右；跨栏的标题和表格不应被拆碎。
